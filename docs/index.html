От данных к проверке

Один район.
Прозрачный анализ.

  1. Собрать временной ряд

    В существующем коде: MODIS для растительности, ERA5 или CHIRPS для осадков. Пайплайн запускается локально; эта страница показывает сохранённый пример.

  2. Оценить статистический сигнал

    RESTREND оценивает тренд после поправки на осадки. FDR уменьшает проблему множественных проверок. Причины изменений требуют независимой проверки.

  3. Подготовить понятный отчёт

    Подготовлена интеграция Claude API для черновиков на русском, казахском и английском. Она получает числовую сводку; специалист проверяет объяснение перед использованием.

Claude: следующий этап продукта

Локальный просмотр запроса уже доступен в репозитории. Реальные запросы к Claude ещё не проверены: нужен API-ключ. Сайт не вызывает модель и не запрашивает ваши данные.

В сохранённом примере рост после поправки на осадки отмечен на 4,3 % площади, снижение NDVI без значимого остаточного тренда — на 1,9 %. Проценты округлены.

  • Наземная проверка качества не проведена. Метрики на синтетике не показывают точность на реальной территории.
  • Для полного ЦУР 15.3.1 не хватает сопоставимых слоёв покрова и почвенного углерода. Screening lower bound по доступным данным — 11,99 %; это отдельная оценка.
  • Данные заканчиваются 2024 годом: пример не показывает текущие пожары или состояние земель в реальном времени.
  • Открытый код — Apache 2.0. Метод упрощённый, сертификация UNCCD не заявляется.
English project brief

SteppeWatch-AI is an early-stage satellite land-monitoring project for Kazakhstan. A Python pipeline and local dashboard identify statistical screening signals that require field investigation. An optional Claude API integration is prepared to draft human-reviewed explanations from numerical summaries in Russian, Kazakh and English. Live model calls and commercial demand have not yet been validated.
