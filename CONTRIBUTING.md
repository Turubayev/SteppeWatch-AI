# Участие в проекте

Нужны почвоведы, геоботаники, специалисты ДЗЗ, представители пастбищных хозяйств.

## Самое ценное — полевая разметка
Классификатор типов деградации учится на реальных точках. Формат `data/field_points.csv`:
`lat, lon, district, label, date, source` + признаки (их можно рассчитать скриптом по координатам).
`label` ∈ {нет деградации, засоление, перевыпас, эрозия, пожар}. Указывайте источник (обследование, институт, экспертная разметка по снимкам).

## Код
* Issue → pull request; перед PR: `pytest -q`.
* Расчёты дублируются на открытом стеке (STAC), чтобы не зависеть только от Google Earth Engine.
* Помните: «деградация» на карте — сигнал для полевой проверки, а не доказательство нарушения.
